# Native history layout model

`HistoryView` replaces fixed rows and reflowed UTF-8 strings with the original 28-byte glyph records. It is independent of SDL rendering and the main loop. `decode_history_pages` reads the native count/records/voice framing, keeps signed coordinates, glyph kind, font/image index and original COLORREF, and decodes only the voice path using the explicit source code page. Unknown record kinds remain available in the parsed page; replay draws only native kinds 3–5, with kind 7 acting as an X-anchor reset.

Evidence: `instructions2/HistoryCore440440.json`, `HistoryCore43fa10.json`, `HistoryCore433f40.json`, `HistorySoundIcon433e50.json`, and the individual instruction handlers. `tools/extract_services_evidence.py` includes the corresponding original byte ranges and verifies the original EXE SHA-256 before extraction. The original `HistoryMode` wrapper 441880 always enters 440440; an integer zero is not a native close instruction.

## Layout

`HistoryWindowSet(layer,L,T,R,B)` enables the specified existing history layer and supplies an LTRB text rectangle. With no arguments it disables the dedicated window. In dedicated-window mode, records move to that layer, the first glyph after a source-layer change or kind 7 supplies the X anchor, and a source-layer change stacks at the accumulated glyph bottom plus `HistoryLineMargin`. Every glyph retains its original font or original/graphic font image index. The measured glyph sizes come from the caller's real font/image providers; there is no invented common font size, wrapping, line height, or row height.

Each page's glyph bounds bottom gains `HistoryRowsMargin`. Constructor bytes 42ba92–42bab2 establish rows margin 30, line margin 0, icon-position type 9, and icon X/Y offsets zero. The loader maps HistoryRowsMargin to context +140b4 / DAT56c874 and HistoryLineMargin to +140b8 / DAT56c878. Both keys are now exposed by `EngineConfig`. Absent INI optionals preserve the caller's constructor defaults.

The native newest start is calculated backward using actual page heights with a **strictly less than** viewport-height condition. It is not a fixed page count. Display proceeds forward from the selected start until accumulated offset exceeds the viewport height. Glyphs whose bottom exceeds the window bottom are hidden; the explicit `all_or_nothing_clip` option applies native DAT56c86a's whole-page hiding rule. Outside dedicated-window mode, only one page is shown and records replay into their original source layers and rectangles.

`HistoryTextColor(normal[, voiced])` overrides the color of glyphs on ordinary versus voiced pages. Its second value is **not a border color**. `SettingsServices` now stores `HistoryVoicedTextColor`; restore and `HistoryOptions::from_settings` accept the older own-save `HistoryTextBorderColor` key as a migration alias. Raw ffffffff preserves each record's color. Native kind 5 graphic glyphs retain their intrinsic image color.

`HistorySoundIconSet(source,normal_group,hover_group)` creates independently measured and positioned normal/hover states. The original 433e50 position modes 0–10 are preserved, including mode 2's extra +5, left/right/first-line-end/last-line-end choices, and configured offsets. Both icon state bounds affect the page bounds. `HistoryDrawIcon.normal_frame/hover_frame` carry their distinct coordinates and sizes; the common x/y/size fields select normal when present, otherwise hover.

## Regions, navigation, voice and closing

The model consumes normalized `AreaServices` registrations, their actual visible-parent translations and sprite groups. Region labels match 440440: Prev=2, Next=3, PagePrev=8, PageNext=9, Head=10, Last=11, Exit=6, ScrollBarH=12, ScrollBarV=13, and voiced page N=10000+N. Native wheel/up/down labels 4/5 also move one entry. Window-mode page buttons move by AreaSetHistoryPageSize; nonwindow mode always moves one. Edge buttons are marked disabled. Vertical dragging accounts for thumb height and maps the remaining track to the native start-index range using truncation. Output area sprites include the current vertical thumb Y. The original horizontal label 12 only redraws; the model does not invent horizontal scrolling.

AreaSetHistoryIndicate definitions expose history-only indication regions and sprites. They are not dispatched as ordinary script areas. AreaSetHistoryMouseR supplies native right-click exit feedback (`layout.right_exit_sound`, native field +38), while right-click itself maps to label 7. The caller supplies `screen_rect` to obtain the native full-window background-exit region when AreaSetHistoryExit is not registered; no game resolution is hardcoded.

Voice activation requests an exclusive voice through hooks, fading the previous/history voices for the observed 100 ms. HistorySoundNumberSet supplies the optional fixed channel; otherwise the host allocates a voice channel. Closing stops the history voice unless HistoryToVoiceContinue is enabled. Advancing beyond the newest start with HistoryExitToNext enabled closes and latches a one-shot `take_advance_request()` for the caller to advance the pending text wait. Ordinary close does not request advance.

## Integration

Build options from `HistoryOptions::from_settings(settings.state(), text_layer)`, then apply engine-config rows/line margins, icon mode/offsets, source encoding, screen bounds and the native clipping flag. Feed each existing `HistoryEntry.native` through `decode_history_pages`, or combine their native bytes and decode once. Provide real layer rectangles/translation, per-record font/image extents, icon-group extents and voice operations. `open(pages,options,&areas)` produces `layout()`: positioned glyphs, normal/hover icon states, regions with native area sprites, visible page indices and current/max start. Render glyphs via `Scene::positioned_text`; draw kinds 4/5 through the registered original/graphic font image sources. The model deliberately keeps those image kinds separate from text rather than converting them to printed control-code strings.

The caller owns scene snapshots/layer visibility, icon/area hover rendering, control sounds, input key mapping and restore on close. It should keep `AreaServices` alive and stable while the model is open. Missing layer/glyph providers and missing voice playback when activated fail explicitly. This module models layout, geometry and voice decisions; it does not claim Windows GDI raster identity, IME behavior, or automatic scene/audio device ownership.

`tests/history_view_tests.cpp` covers native record decoding, distinct ordinary/voiced colors, per-record fonts, source-layer and LF anchors, strict newest packing, configurable page navigation, area hit gating, voice channel/continue/fade behavior, one-shot ExitToNext, independently positioned icon states, vertical dragging and whole-page overflow clipping. ASan/UBSan tests passed. An optional savedata path plus explicit encoding validates a real native history block read-only; commercial sample bytes are not included in normal tests.
